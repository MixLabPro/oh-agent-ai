# Agent City：场景优先与渐进式 HUD SPEC

日期：2026-10-04。状态：设计目标已由用户确认；实现与验收待完成。本文不表示当前 App 已达到目标。

## 1. 产品方向与适用范围

Agent City 是一个可探索的数据世界，不是以 3D 为背景的仪表盘。默认观看，选择后解释，需要时操作。

参考 Tiny Skies 的使用态（世界占据中心，少量 HUD 退到边角），不照搬启动页的大标题、载具选择、等级、多人动态或任务机制。参考基线为 tinyskies `2659a5c`；`/tmp/tinyskies` 仅为临时副本，不是构建依赖。参考台账见原仓库 `TINYSKIES_PORTING_ANALYSIS.md`；引用代码前仍需核对授权证据和范围。

本文约束宿主工具呈现、插件 HUD、交互状态和体验验收。地理与布局归 `CITY_PLANNING_SPEC.md`，渲染归 `CITY_RENDER_QUALITY_SPEC.md`，视频归 `CITY_SHARE_SPEC.md` 与最新 MP4 文档，插件边界归应用层架构规范。涉及 UI 呈现的旧“HUD 沿用现有产品”描述由本文取代；数据、布局和投影契约不因此改变。

非目标：球形世界、飞行游戏、WASD 探索、额外环境特效、多人联网、独立 App 窗口、投影分页重写。它们不能因“向 Tiny Skies 学习”被自动加入本期。

## 2. 默认界面

| 区域 | 常驻内容 | 按需内容 |
| --- | --- | --- |
| 宿主顶部 | 侧栏开关、City 标题、航拍、更多操作 | 更多菜单内：时间范围、画质、标签、重置视角、拍照、导出视频、城市设置 |
| 插件左上 | 一个紧凑摘要入口，如 `264 会话 · 13.47B tokens` | 摘要面板：精确数字、活跃状态、城区列表、载入范围 |
| 城市内部 | 建筑；默认保留简短城区标签 | 悬停提示、点击建筑/城区后的详情 |
| 插件底部 | 小型“回放”入口与实时状态 | 打开后显示游标、播放/暂停、速度、时间、回到实时、关闭 |
| 临时反馈 | 只在操作或异常时出现 | 导出进度/取消、恢复操作、可访问的说明 |

删除场景内大号 Agent City 标题、品牌眉题、常驻长状态段落和页脚口号。不用隐藏控件的方式减少必要的错误、范围受限或进行中任务反馈。

默认显示城区名，不显示每栋建筑的永久文字。建筑详情通过选中获得；标签开关保留在更多菜单。默认画质与数据范围沿用已有产品配置，不为视觉效果悄悄扩大取数范围。

## 3. 信息披露与数据诚实

- 摘要数字使用本地化缩写；展开后可查看精确值。数字与单位不能溢出或遮挡入口。
- 摘要显示的是已载入会话及其统计，不是全历史。入口可显示 `已载入 264/264 ⓘ`；若被截断，必须常驻显示“范围受限”文字标记，不能只藏在 tooltip 中。
- 面板说明取数窗口、已返回数量/总量、最多 500 条近期会话，以及统计与回放仅覆盖已载入数据；查询失败时不用旧数字伪装成功。
- Findings 仅有部分投影时，异常数量旁标明“部分”。不默认把大段异常统计叠在整个城区列表上。
- 建筑高度表示 token 规模，施工/生长是可视化近似，不是任务完成度。回放首次打开可见简短提示，详细解释可展开且支持键盘操作。
- 天气、鸟群、航线等装饰不能暗示业务成功、异常或活跃。数据时间、环境时间和动画时间保持既有语义，本期不重新定义。
- 不扩展数据字段、SQL、日志或网络权限；插件继续通过注册 Rust 投影消费声明的数据。

## 4. 状态与操作规则

### 4.1 观看与选择

默认无展开面板。摘要入口展开城区/统计；点击城区聚焦，点击建筑打开详情。统计面板和建筑详情同一时刻只展开一个；关闭不重置相机。空白点击不得被全屏透明浮层拦截。

Esc 优先关闭当前菜单或面板；在无弹层的航拍中退出航拍。焦点返回触发入口。宿主导航始终可用，不被插件覆盖。

### 4.2 回放

实时状态不常驻完整控制条。打开回放才展开控制；播放后不能因空闲超时隐藏控制。暂停保留游标；关闭控制不暗中回到实时，底部入口应显示“回放中”及恢复入口。显式“回到实时”结束回放。

开始播放使用已载入数据的有效回放起点，不从无建筑的查询起点等待。没有数据时入口说明原因并禁用播放。

### 4.3 航拍与导出

进入航拍暂时隐藏统计、建筑详情、回放面板和普通标签，保留明确退出入口；退出恢复原相机及进入前的面板状态。现有代码如不支持恢复，需作为实现任务，不得声称已完成。

导出仍采用现有后台逐帧 MP4 方案；本期只调整入口。导出期间进度和取消常驻可见，不被更多菜单收起，不与现场航拍状态混淆；切换 Tab 的取消规则沿用现有契约。

### 4.4 Tab 与布局切换

Tab 返回保留现有城市实例、视角、选择、回放游标与合法面板状态；隐藏期间不保留键盘捕获。宿主侧栏切换只更新插件视图边界，不重建场景或触发恢复/语言同步副作用。

瞬时白闪/黑闪是独立未闭合问题。静态落点截图、源码守卫或编译通过均不能证明其已修复。截图占位如后续采用，仅为本地短暂过渡兜底，需要处理新尺寸就绪、超时与资源释放，不应成为持续高频截图链路。

## 5. 视觉、响应式与可访问性

- 画布贴合插件插槽，无内层页面圆角或外边距；宿主负责窗口外缘，局部面板可圆角。
- HUD 使用轻量局部底板，非一排大卡片。背景会随昼夜变化，不能依赖裸白字或透明度保证对比；普通文字目标对比度至少 4.5:1。
- 样式随宿主语言和主题更新；详情原始摘录不自动翻译。图标按钮必须有可访问名称，重要状态不能只靠颜色。
- 默认 HUD 投影总面积目标不超过可用插件视口的 12%（不计城区标签及临时异常反馈）；这是设计验收目标，不是已测结果。
- 统计/详情按面板布局避让回放控制，不用几个独立固定 bottom 值猜高度。窄窗口详情可成为可关闭抽屉，内部滚动，禁止盖住宿主导航或工具栏。
- 面板打开使用轻量反馈并支持 reduced-motion；不自动旋转首屏，不为“沉浸”自动收起宿主侧栏。用户仍可主动切换宿主侧栏。
- 所有菜单、范围选择、回放和关闭操作可通过键盘完成；可见焦点不被浮层遮挡。

## 6. 插件与宿主责任

插件定义领域操作和本地 HUD；宿主负责通用菜单/分组呈现与原生视图边界。不在宿主添加 City 专属菜单分支或读取插件 DOM。

若现有 toolbar 描述只支持平铺按钮/select，需以向后兼容的通用分组/溢出模型扩展协议，并同步浏览器 iframe 与原生 WebView 适配和契约测试。保留旧描述符的降级呈现；不能直接删工具导致功能不可达。

插件故障仍由宿主给出明确失败/重试界面；精简 HUD 不能吞掉错误。iframe 与原生使用相同领域接口，但合成器和尺寸同步不同，必须分别验收。

## 7. 实现顺序与完成条件

| 阶段 | 内容 | 完成条件 |
| --- | --- | --- |
| U1 | 通用工具分组/更多入口、移除重复标题、紧凑摘要 | 所有原有操作可达；宿主无 City 特判；默认 HUD 面积达标 |
| U2 | 按需统计/城区、回放折叠、选择与焦点规则、响应式 | 实时/回放/选择/异常状态可理解；小窗口无重叠；中英文键盘流程通过 |
| U3 | 航拍恢复、Tab 状态连续性、双容器验收 | 原生 bundle 与浏览器验证；视觉和功能回归证据齐全 |

本期不新增鸟、飞机、鲸跃或 LensFlare；先确保已有环境效果不被面板遮挡。新增探索模式另立 SPEC。

验收矩阵：窗口内容区 640×480、760×560、1100×760，以及大窗口；侧栏展开/收起；中英文；宿主支持的明暗主题；白天/夜间；空数据、正常、截断、部分 Findings、失败；实时、回放、选择、航拍、导出。以插件实际可用宽高再检查布局，不能只测外窗口尺寸。

新旧视觉对比固定数据集、投影范围、种子、视角、时间和画质；不同窗口/数据的统计数字不得用于证明迁移完整性。截图记录版本与 bundle 来源。

闪烁测试必须覆盖动作发生后的过渡阶段，记录采样帧率/时间覆盖及漏采区间；若工具只能获得落点截图，结果标注“瞬时闪烁未验证”。源码/类型/协议测试、静态布局 UAT、瞬时绘制稳定性分开报告。
