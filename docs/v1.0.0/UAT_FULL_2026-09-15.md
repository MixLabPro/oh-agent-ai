# v1.0.0 UAT 执行记录（2026-09-15）

## 结论

本轮完成了安装包启动、真实 Authority DB 的只读数据对拍，以及隔离环境中的
控制面、计费工作流和端到端回归。数据接口没有发现未解释的不一致；但桌面窗口
尚无法被 macOS 辅助功能服务读取，且真实库的数据覆盖本身为部分状态。因此，本轮
**不能宣布完整 UAT 通过，也不能关闭 Beta 发布门禁**。

## 真实 Authority DB：只读数据对拍

使用安装包内 CLI 的公开 MCP 对真实 `~/.agent-vitals` 执行检查：

- `19 EXACT / 4 PARTIAL / 2 BLOCKED / 0 MISMATCH`。
- 当日 `usage_hourly`、`data daily`、会话下钻和峰值小时逐宿主守恒；MCP 与 CLI 一致。
- 重复导入/中断恢复的重放校验通过；无泄露路径、原生会话 ID 或正文。
- Authority SQL 已启用，schema 为 13，最近同步成功。

`PARTIAL`/`BLOCKED` 来自真实库缺少可验证样本或覆盖不完整，不是数值不一致：

| 领域 | 状态 | 原因 |
|---|---|---|
| Issues 重复错误与重试链 | PARTIAL | 可用证据覆盖为 partial。 |
| 时间线关联 | PARTIAL | workflow 关联覆盖为 partial。 |
| 跨宿主 raw 模型归一 | PARTIAL | 当前 v1 输出保留 host_raw，未产生可完整验证的 canonical 样本。 |
| Skill 成功率与版本回归 | BLOCKED | 真实库没有可比较的 skill 样本。 |
| DSH / WorkBuddy | 未完成数据完整性验收 | DSH 没有可用数据，WorkBuddy 已过期；总览应呈现 unavailable/stale，不能显示成功或归零。 |
| 路由与价格 | 未完成金额完整性验收 | 部分 provider/route 仍未确认，必须保持 unresolved / metered estimate，不可宣称实际账单。 |

内部 MCP 的只读补充检查为 `21 EXACT / 4 PARTIAL / 2 BLOCKED / 0 MISMATCH`；增加验证了
authority audit、只读 SQL 白名单与事实安全视图。
