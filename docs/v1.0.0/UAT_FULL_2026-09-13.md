## 证据分层与勾选纪律

- **Vite 补充**：浏览器页使用隔离 mock；只证明前端交互与文案状态，不写入 Authority、不读取真实日志，也不替代 `.app`、CLI 或 MCP。
- **真实 `.app`**：本轮只确认包体可启动并观察到部分页面；套餐确认面板、失败注入重试、声明/重算、退出重开、系统通知和目录选择器等关键路径没有取得完整正向证据。
- **CLI / MCP**：CLI 对拍、公开/内部 MCP 冒烟和 typed control-plane 操作分别证明数据契约、只读/写入边界或隔离控制动作；它们不能替代桌面用户路径。MCP 的 `PARTIAL` 也不升级为正式通过。
- **失败态**：只有同时看到错误注入、非零/`warn` 或 `Unavailable` 语义、受影响宿主隔离和可恢复入口，才算失败态证据；契约测试或浏览器 mock 不单独关闭真实失败态 UAT。

因此，下表中的“数据层/契约证据”仅记录已存在的底层或接口证据；“桌面真机路径”缺失时，正式结论统一保持“不勾选”。
