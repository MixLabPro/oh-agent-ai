    Claude CodeCodexWorkBuddy → 工作记录会话 · 事件 · 轨迹

    按日期、来源和会话查看 Agent 留下的事件与轨迹。来源没有记录的字段，明确标为不可用。

  2. 02 · 对账
    按量估算¥38.60估算

    知道花了多少，也知道数字准不准。

    订阅、按量估算与有依据的支出分栏显示，从不相加。缺价格或缺归属时保留「未知」，不把猜测当账单。

  3. 03 · 检查
    连续失败3 次

把疑问说清楚。

少一点猜测，多一点确定。

需要提供 API Key 或上传日志吗？

不需要提供 API Key，也不需要上传日志。桌面应用在本机读取受支持工具已有的使用记录；遇到系统权限限制时，可能需要你授权读取对应位置。

支持哪些电脑和 Agent？

当前提供 macOS 测试版。运行时会话与用量重点覆盖 Claude Code、Codex、DeepSeek Harness 和 WorkBuddy；不同宿主、版本与字段的统计、成本和轨迹能力并不完全相同。OpenClaw、Hermes 当前主要是安装与 Skill 层检查，不属于同等的运行时覆盖。

第一次打开没有数据怎么办？

请先确认受支持的 Agent 已有本地使用记录，再检查应用中的数据源状态和读取权限。没有日志、没有权限和暂未同步是不同状态，不会用虚构数据代替你的结果。

显示的金额就是我实际付的钱吗？

不一定。按量估算来自可用的用量和价格信息，不能直接视为扣款。订阅、估算与有依据的已知支出需要分别理解；价格、路由或账单缺失时会保留未知状态。

它真的能帮我省钱吗？

Agent Vitals 帮你看清用量与成本、定位高消耗或反复失败的会话，为调整提供依据。实际能否省钱取决于你的计费方式与后续行动。固定订阅下，减少 Token 不一定减少账单；我们不承诺自动省钱或固定节省比例。

它能判断 Agent 把工作做对了吗？

不能。Agent Vitals 记录受支持来源留下的用量、事件、失败和轨迹证据，帮助你定位值得检查的会话；它不会把「消耗低」当成「结果正确」，也不会替你验收最终交付。

软件是否开源？

是的，源代码采用 MIT 许可证。你可以在 GitHub 查看代码、许可证和发行说明，也可以提交问题与反馈。网页中的数字为演示数据，不是用户统计或节省承诺。
