Before you download

Straight answers.

Less guessing, more certainty.

Do I need an API key or to upload logs?

No API key, no uploads. The desktop app reads usage records your supported tools already keep locally; if the system restricts access you may need to grant read permission.

Which computers and agents are supported?

A macOS beta is available. Runtime sessions and usage focus on Claude Code, Codex, DeepSeek Harness, and WorkBuddy; statistics, cost, and trace coverage differs by host, version, and field. OpenClaw and Hermes currently get install- and skill-level checks only — not the same runtime coverage.

What if the first launch shows no data?

Confirm your supported agents have local usage records, then check data-source status and read permissions in the app. No logs, no permission, and not-yet-synced are different states — none is ever filled with made-up data.

Is the displayed amount what I actually pay?

Not necessarily. Metered estimates come from available usage and pricing and are not charges. Subscription, estimate, and evidenced known spend are separate; missing price, route, or bill data stays unknown.

Will it actually save me money?

Agent Vitals shows you usage and cost, and pinpoints high-spend or repeatedly failing sessions so you can act. Whether that saves money depends on your billing and what you change. On a fixed subscription, fewer tokens don't always mean a smaller bill; we promise no automatic savings or fixed ratios.

Can it tell whether the agent did the job right?

No. It records the usage, events, failures, and trace evidence your sources leave, and helps you find sessions worth checking. It never treats「low spend」as「correct output」, and it does not accept deliverables for you.

Is it open source?

Yes, MIT licensed. Browse the code, license, and releases on GitHub, and file issues. Numbers on this page are demo data — not user statistics or savings claims.
