它真的能帮我省钱吗？+

Agent Vitals 帮你看清用量与成本、定位高消耗会话，为调整提供依据。实际能否省钱取决于你的计费方式与后续行动。固定订阅下，减少 Token 不一定减少账单；我们不承诺自动省钱或固定节省比例。

显示的金额就是我实际付的钱吗？+

不一定。按量估算来自可用的用量和价格信息，不能直接视为扣款。订阅、估算与有依据的已知支出需要分别理解；价格、路由或账单缺失时会保留未知状态。

需要提供 API Key 或上传日志吗？+

不需要提供 API Key，也不需要上传日志。桌面应用在本机读取受支持工具已有的使用记录；遇到系统权限限制时，可能需要你授权读取对应位置。

支持哪些电脑和编程工具？+

当前提供 macOS 测试版，面向 Claude Code、Codex 等本机日志来源。不同工具和版本的记录字段可能不同，统计与轨迹覆盖会有所差异。请在发布页确认当前安装包的系统要求、芯片架构与支持说明。

第一次打开没有数据怎么办？+

请先确认受支持的编程工具已有本地使用记录，再检查应用中的数据源状态和读取权限。没有日志、没有权限和暂未同步是不同状态，不会用虚构数据代替你的结果。

软件是否开源？+

是的，源代码采用 MIT 许可证。你可以在 GitHub 查看代码、许可证和发行说明，也可以提交问题与反馈。网页中的数字为演示数据，不是用户统计或节省承诺。
